# 暁光の剣士 生物基礎（ゲーム本体）

高校「生物基礎」を学ぶ成長型RPG。スマートフォンのブラウザで遊べます。

- 遊ぶ：このリポジトリの GitHub Pages のアドレスを開く。
- 問題と数値：別のリポジトリ「このリポジトリの名前-data」の `content/` にあります。ゲームはそこから問題を読みこみます（そのリポジトリは GitHub Pages で公開しません）。
- 先生の編集：アドレスの最後に `?teacher` を付けて開き、「先生の設定」でトークン（問題データのリポジトリだけに使えるもの）と暗証番号を決めると、ゲームの「データ編集」から保存できます。
- このリポジトリ（ゲーム本体）は、トークンでは書きかえられません。本体を変えるときは、GitHubの画面から index.html を置きかえます。
- 記録：遊ぶ人の端末のブラウザに保存されます（サーバーには送りません）。
